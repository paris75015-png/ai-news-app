# 国際深掘り（editorialVersion = 1）

**先に [共通.md](共通.md) を読むこと。** ここには国際深掘り固有の規則だけを書く。

由来: Cowork スキル `english-news-digest` v5.2（2026-09）。
リポジトリへの移植にあたり、**守備範囲を大きく変更した**。基本媒体も入れ替えた。変更点は末尾の改訂履歴にある。

---

## 目的

読者は英語の各媒体本文を自力で読むことができる。国内ニュースは日経電子版と国内深掘りで別途網羅している。
したがってこの系統は**海外（英語圏）ニュースに特化**する。必要とされている理由は次の4点である。

1. 日本メディアにはない視点・フレーミングが欲しい
2. 世界が何を重要視しているかを把握したい
3. 「へぇ」で終わらず構造的理解まで到達したい
4. 日本メディアのエンタメ化・バイアスから一旦距離を置きたい

## 守備範囲 — ここが移植前と最も変わった

**主題は「日本で報道が薄い論点」である。**

戦争と大規模災害は、日本のメディアでも十分に報道される。
**日次の死者数更新・被害額更新を、この系統で繰り返さない。** それは読者が日経とテレビで既に得ている。

| 扱い | 対象 |
|---|---|
| **深掘り（`deep`）** | 日本で扱いが薄い事案。日本のデフォルトのフレームと異なる角度。構造的な潮流の転換点 |
| **短信（`brief`）** | 世界の重要事のうち、日本でも報じられているもの。戦争・災害の続報はここに畳む |
| **例外的に深掘り可** | 戦争・災害でも、**日本の報道にない視点を一文で言語化できる場合に限り**深掘りに上げてよい（例：「同じ空爆を、湾岸各国の国内政治の文脈で読むとどう見えるか」）。死者数の更新は視点ではない |

対象地域として意識的に拾う: アフリカ、中南米、南アジア、東南アジア、中央アジア、欧州域内政治、多国間機関の動き。

**「幅」がこの系統の価値である。** 読者が求めているのは、世界のどこで何が動いているかの見取り図であって、特定の紛争の日次追跡ではない。
同じ系統の続報が紙面の半分を占めた時点で、件数や字数が規定内でもこの成果物は目的を果たしていない。

## 基本媒体（移植時に入れ替えた）

**基本6媒体**: BBC、The Guardian、Al Jazeera、Wired、TechCrunch、Nature

**媒体充足の下限: 基本6媒体のうち最低3媒体を出典に含めること。** 下限を満たせなかった場合は `productionNote` に理由を明記する。
この下限は `access: "excerpt"` でも満たされる。

媒体は分散させる。

- **BBC / The Guardian / Al Jazeera** … 速報基準・地域の広さ
- **Wired / TechCrunch** … 原則1件（飛び抜けて重要な日のみ2件）
- **Nature** … 実質のある日だけ。毎日捻出しない（0件の日もあってよい）

### 補助媒体

基本媒体で届かない事案は以下で代替し、出典に明記する。

NYT、Washington Post、PBS、NPR、Euronews、CNBC、CBS News、NBC News、The Information、WSJ、Nikkei Asia、Fortune、Axios、Al Jazeera、各国の主要紙（地域の事案では現地の有力紙を優先する）

地域の事案では、**その地域の一次媒体を1回探す**。中南米なら Rio Times や現地紙、東南アジアなら Bernama・Philstar、アフリカなら現地の有力紙。
これらは基本媒体の代替としてカウントしないが、日本で報道が薄い事案ではしばしば唯一の情報源になる。

### 検索の実務

- 日付ベースの検索（`"world news September 18 2026"`）はカテゴリのトップページを返しやすい。
  **事象の種類で検索する**（`"election"`、`"CPI report"`、`"central bank"`、`"summit"`、`"AI regulation"`）＋おおまかな日付
- 候補が定まったら記事本文を取得する。検索スニペットだけで書かない
- Wikipedia の Current Events ポータルを構造的な突き合わせに使ってよい。ただし出典にはしない

## 系統別の上限（移植時に強化）

1日のうちで、同一系統から採用してよい件数の上限。上限を超える材料があるときは、最も高スコアの1件に統合する。

| 系統 | 上限 | 階層 |
|---|---|---|
| 中東（イラン／ホルムズ／ガザ／イスラエル／湾岸） | **1件** | 原則 短信 |
| ウクライナ・ロシア | **1件** | 原則 短信 |
| 単一の災害・事故の続報 | **1件** | 原則 短信 |
| 単一企業の続報（Meta、エヌビディア等） | **1件** | 原則 短信 |

「原則 短信」を破って深掘りにするには、**日本の報道にない視点を `body` の中で一文として書けること**が条件になる。
書けないなら短信に留める。死者数・被害額の更新は視点ではない。

**主要系統以外からの下限: 上記3系統（中東／ウクライナ・ロシア／進行中の大規模災害）に該当しない記事を、1日あたり最低8件含める。**
満たせなかった日は `productionNote` に理由を書く。

> 移植前は上限が中東2件・ウクライナ1件・災害1件、主要系統以外の下限が3件だった。
> 2026-09-18版では主要3系統が14件中4件（29%）を占め、深掘り相当の上位2件もイラン情勢だった。
> 新しい守備範囲では、これらは短信に畳む。

## セクション構成

`section` に入れる値と、その中身。**移植前と順序が変わっている。** `unseen` が筆頭に来る。

| `section` | 名称 | 深掘り | 短信 |
|---|---|---|---|
| `unseen` | 日本では見えにくい論点 | 3〜4件 | — |
| `structural` | 構造的トレンドの進展 | 2〜3件 | 0〜2件 |
| `science` | サイエンス&知の最前線 | 0〜1件 | 0〜2件 |
| `world` | 世界の動き | 0〜1件 | 6〜8件 |

- **`unseen`** … 日本メディアでの扱いが薄い、あるいは日本のデフォルトのフレームと異なる角度から重要と判断できる事案。**この系統の中心**。確信度が低い場合は採用しない
- **`structural`** … 継続的潮流の今日的展開（AI規制、米中技術戦争、エネルギー転換、多国間機関の再編など）
- **`science`** … Nature・主要研究機関発のブレークスルーで社会的含意を伴うものに限定。日々の医学研究の細部は採用しない
- **`world`** … 日本でも報じられている世界の重要事。**戦争・災害の続報はここに畳む。**原則すべて短信

### 総量と件数

**目標: 深掘り 5〜7件、短信 8〜10件、合計 14〜16件、記事本文の合計 4,500〜6,000字。**

- **大きな出来事がない日は、深さではなく幅に倒す。** 件数を確保できない日でも、既存記事を長くして埋めない
- `science` のみ下限0件でよい。実質がなければスコアなしの短いまとめ段落に置き換えてよい
- セクションを丸ごと省略する場合は `productionNote` に理由を書く
- **下限割れが2日続く場合は収集手順を疑う。** 検索の当たり方を変える

## 深掘りの節の構成

`概要兼背景` → `今後の影響` → `日本・アジアへの含意` →（該当時）`視点の差`

### 【日本・アジアへの含意】の質

**接続が薄い場合は、この節ごと省略してよい。捻出は禁止する。**

- ✗ 「独立記念日に大規模災害対応が重なったことは、行政資源の切り替え体制という点で日本の防災計画にも示唆を与える」（捻出）
- ✓ 「津波が4州16地点で観測された。1992年のフローレス地震では津波で約2,500人が死亡している。同型の海溝型地震として、日本の津波警報運用にも比較対象となる」（実質）

**判定法: その含意が、別の国で起きた別の事件にもそのまま貼れるなら、それは捻出である。**

### 含意を書く前に日本の固有名詞を1回探す

一般論に流れる原因は、禁止（捻出するな）だけを課して探索を課していないことにある。
**含意を書く前に、その事案の原記事に日本の固有名詞が出ていないかを1回確認する。**

探す対象は企業名・地名・省庁名・金額・人名。事案名＋「Japan」「Japanese」「Tokyo」「SoftBank」等で1回検索すればよい。
見つかればそれが含意の中心になる。見つからなければ節ごと省略する。

> 取りこぼしの実例
> - エヌビディアのオハイオ案件 … 施設を建設・所有するのはソフトバンク傘下のSBエナジーであり、貿易合意の一環として日本が同発電事業に330億ドルの投資を約束していた。書かれたのは「日本の商社・電力会社も投融資を拡大させている」という一般論だった
> - 駆逐艦の電源喪失 … 修理を担ったのは横須賀の艦船修理廠で、当該艦も横須賀に帰投した。書かれたのは「米艦隊の即応性は日本の安全保障環境に直結する」という一般論だった
> - 簿外債務の推計 … 話題の3兆ドルの前段にある1兆6500億ドルの集計を最初に出したのは日経だった

**この節は、書かないより一般論を置くほうが悪い。** 該当がなければ丸ごと省略する。「該当する直接の波及経路は薄い」という定型句を繰り返さない。
推測が混じる場合は「FTの示唆では」「直接の言及はないが」など根拠の質を示す。

### 【視点の差】

複数媒体でフレーミングが大きく異なる、または**日本メディアと海外メディアの扱いが大きく違う**場合のみ追加する。全記事には付けない。
新しい守備範囲では、この節が `unseen` の記事の要になることが多い。

## 短信のフォーマット

`summary` に150〜250字。節のラベルは付けない。`body` は null。

事実のみを書く。背景説明・影響予測・一般論を入れない。数値は発表主体を添える。

```
国連人道問題調整事務所は9/18、スーダンの飢餓人口が2,400万人に達したと発表した。
世界の食料危機人口の3割を占める。援助資金の充足率は19%にとどまる。
```

**日本への直接の経路がある場合に限り、末尾に1文（30字以内）を足してよい。** 捻出は禁止。判定基準は `日本・アジアへの含意` と同じ。

## 今日の教養（1〜2件）

本日採用した記事の中から選び、各**350〜450字**で解説する。`essays` に入れる。

選定の3層フィルターは [国内深掘り.md](国内深掘り.md) と同じ。3（他で読めない角度か）を最も厳しく見る。
**短信を題材にするのが望ましい。** 短信が幅を、教養が深さを担当する分業になる。深掘りは本文で既に厚いので、教養で重ねると重複が増える。

論点の切り替わり（背景→現状→課題→日本への示唆）で3〜4回改行を入れる。日本にとっての示唆を1〜2文添える。

## 出力前の自己検証（国際深掘りの追加分）

[共通.md](共通.md) 10節に加えて確認する。

**守備範囲**

- [ ] **深掘りの中心が `unseen` になっているか。**戦争・災害が深掘りの上位を占めていないか
- [ ] 系統別の上限を超えていないか（中東1件／ウクライナ・ロシア1件／単一災害1件／単一企業1件）
- [ ] 上限系統を深掘りに上げた場合、**日本の報道にない視点を一文で書けているか**
- [ ] 主要3系統に該当しない記事が8件以上あるか。満たせない場合、`productionNote` に理由を書いたか
- [ ] 日本でも十分報じられている事案が深掘りになっていないか

**媒体**

- [ ] 基本6媒体（BBC／Guardian／Al Jazeera／Wired／TechCrunch／Nature）のうち何媒体を出典に含めたか。**3未満なら再収集する**
- [ ] Reuters・FT・Bloomberg・AP・Science を `access: "body"` と書いていないか（これらは取得できない）
- [ ] コンテンツファーム・自動転載サイトが出典に残っていないか
- [ ] 地域の事案について、その地域の一次媒体を1回探したか

**含意と階層**

- [ ] `日本・アジアへの含意` を書く前に、原記事に日本の固有名詞が出ていないかを1回検索したか
- [ ] `日本・アジアへの含意` が、別の国の別の事件にもそのまま貼れる一般論になっていないか。なっているなら**削る**
- [ ] 続報を1件ずつ書き出し、初期点数と比較したか。深掘りに上げた続報について、軌道が変わったことを `continuity.note` に書けているか
- [ ] 数値の更新（死者数・被害額・避難者数）だけを理由に続報を昇格させていないか
- [ ] 直近3日に登場した系統について、前提復習の定型文を書いていないか
- [ ] 同一の発言・発表を、背景として2日以上引いていないか
- [ ] 死者を伴う災害・紛争が、経済ニュースより不当に低いスコアになっていないか
- [ ] 深掘り5〜7件・短信8〜10件・本文合計4,500〜6,000字に収まっているか
- [ ] 教養は350〜450字か。改行が3〜4回入っているか。本文と重複する数字が2つ以上ないか
- [ ] 教養に括弧書きの訳語を付けた場合、その訳語は実在するか

## 改訂履歴

**v1（2026-09-20）** — Cowork スキル `english-news-digest` v5.2 をリポジトリへ移植。変更点は5つ。

1. **守備範囲を「日本で報道が薄い論点」に転換。** 戦争・大規模災害は日本でも十分に報道されるため、日次の続報を短信に畳む。深掘りに上げるのは、日本の報道にない視点を一文で言語化できる場合に限る。セクション順を変更し、`unseen`（日本では見えにくい論点）を筆頭に置いた。
2. **基本媒体を入れ替えた。** 移植前の基本8媒体のうち Reuters（401）・FT（403）・Bloomberg（403）・Science（403）は機械的に取得を拒否される。AP も同様。2026-09-17版・09-18版はいずれも「到達できなかった」と記録しながら基本媒体を変えておらず、実際の紙面は Axios・Fox News・Gizmodo・Rio Times で埋まっていた。読めることを実測した BBC・The Guardian・Al Jazeera・Wired・TechCrunch・Nature を基本6媒体とし、下限3媒体は維持した。
3. **系統別の上限を強化。** 中東 2件→1件。主要系統以外の下限 3件→8件。
4. **3階層（主記事／標準／短信）を2階層（深掘り／短信）に整理。** 深掘り600〜800字、短信150〜250字。中間層を廃したぶん、深掘りは重要度に応じて500〜800字の幅を持たせてよい。
5. **保存先を Google Drive からリポジトリの JSON へ変更。** 直近3日分の確認も `public/data/archive/` を読む。制作記録（※注記・内訳）は `productionNote` へ移し、紙面から分離した。

移植元 v5.2 までの改訂履歴と失敗実例は [共通.md](共通.md) に統合した。
